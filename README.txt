PratoReal V0.1 — AR real
Arquivos:
- index.html
- xburger_13cm.glb

Como testar:
1. Coloque os dois arquivos na mesma hospedagem HTTPS.
2. Abra index.html no celular.
3. Toque em “Ver tamanho real na sua mesa”.
4. Em aparelhos compatíveis, o model-viewer encaminha para o modo AR disponível.

Observação: o GLB é um modelo procedural de demonstração, não uma digitalização fotorealista de um hambúrguer real. A escala do modelo foi construída em metros e configurada para ~13 cm de largura.
